# Museo Imperial

Réplica de las siete páginas públicas del sitio de referencia, con sus imágenes, fuentes, estilos y JavaScript originales.

## Vista local

```sh
python3 -m http.server 4173 --directory dist
```

Abrir http://localhost:4173. El formulario original prepara un correo dirigido a andres@arenalprimegroup.com mediante la aplicación de correo del visitante.
